**Companion to:** [../POSA_PREP.md](../POSA_PREP.md) · Break-day track — "Strong skills in HTML/CSS" from the JD.

**Format (differs from other tracks):** CSS can't be graded by jest. Each folder gets `README.md` with an **acceptance checklist**, a starter `index.html` + `styles.css`, and you verify in the browser (resize, keyboard-tab, zoom 200%).
