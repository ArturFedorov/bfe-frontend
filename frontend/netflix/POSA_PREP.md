## Harness notes (applied when task folders are generated)

- React tasks need: `react`, `react-dom`, `@types/react`, `@types/react-dom`, `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`; `jsx: "react-jsx"` in tsconfig. Tests carry a `/** @jest-environment jsdom */` docblock so the global jest config stays node.
- Node tasks stay framework-free (plain handlers + in-memory stores) except the GraphQL topic, which needs the `graphql` package.
- CSS tasks are browser-verified (starter `index.html` + `styles.css` + acceptance checklist in the README) — jest can't see layout.
- Same contract as algo: README + stub = the prompt, tests = the grader, no solution files.
